# Introduction to Artificial Intelligence Lab 0

This lab focuses on setup and foundation of lab designing to get us ready for ML course. It contains a setup part and coding part. 
The Setup focuses on installing the tools such as python, VS Code, GitHub and Google Colab. This aims to create a professional working enviornment before an actaul work. 

The Coding part focuses on three libraries: 
NumPy — numerical computing, array operations, and matrix math
Pandas — loading, cleaning, and analyzing tabular data
Matplotlib/Seaborn — visualizing data and findings

Generally, this lab is aimed to make sure to start from the same basline and get ready for upcoming labs.
